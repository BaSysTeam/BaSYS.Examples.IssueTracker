# Требования к BaSYS Issue Tracker

В этой папке зафиксированы требования и проект системы для сбора обращений и управления разработкой внутри небольшой команды BaSYS.

Документы:

- [functional-requirements.md](functional-requirements.md) — назначение, границы MVP и функциональные требования;
- [domain-model.md](domain-model.md) — предметная модель, связи, жизненные циклы и правила обработки ТЗ;
- [basys-architecture.md](basys-architecture.md) — проект системы в терминах метаданных BaSYS.

Статус документов: проект требований для последующей реализации метаданных. В этой версии репозитория код и прикладные метаданные системы еще не создаются.
